# 📄 PDF索引ファイル命名ツール

納品書のPDFを、電子帳簿保存法のルールに沿ったファイル名に**自動でまとめて変換**するWebツールです。

🔗 **使ってみる**: [https://pdf-indexer-beta.vercel.app](https://pdf-indexer-beta.vercel.app)

---

## 💡 どんなツール？

経理業務でPDFを保存するとき、こんなルールでファイル名をつける必要がありますよね。

```
20260101_株式会社〇〇_110000.pdf
```

このツールを使うと、PDFの中身を自動で読み取って、このルールに沿ったファイル名に**まとめて変換**できます。

> ⚠️ **対応しているPDFについて**
> テキストが埋め込まれたデジタルPDF（電子で発行されたもの）のみ対応しています。
> 紙をスキャンしたPDFや手書きのPDFは自動抽出できません。
> ただしPDFをプレビューしながら手入力することは可能です。

---

## 🪄 使い方の流れ

**STEP 1 ： PDFをアップロード**

納品書のPDFをまとめてドラッグ&ドロップするだけ。自動で日付・会社名・金額を読み取ります。

**STEP 2 ： 内容を確認・修正**

読み取り結果を一覧で確認できます。
- PDFをその場でプレビューしながら内容をチェック
- 読み取りがうまくいかなかった項目は手入力で修正
- 不要なファイルは除外することも可能

**STEP 3 ： ダウンロード**

「一括確定」ボタンを押すと、変換済みPDFのZIPファイルと索引簿CSVが生成されます。

> 🔒 アップロードしたPDFはダウンロード完了後に自動で削除されます。

## ⚙️ 機能一覧

- PDFのドラッグ&ドロップアップロード
- 日付・会社名・金額の自動読み取り
- PDFプレビューで確認しながら手入力修正

## 👥 会社名の自動入力について

PDFに記載されている電話番号をもとに、あらかじめ登録された取引先データと照合して会社名を自動で入力します。

**現在は管理者のみ取引先データの登録・更新ができます。**
画面から登録できる機能は今後追加予定です。

<details>
<summary>技術者向け：取引先データの管理方法</summary>

取引先データはセキュリティ上の理由からソースコードに含めず、RenderのEnvironment Variables（環境変数）に `MASTER_DATA` というキー名でJSON形式で管理しています。

```json
[
  {"tel": "03-1234-5678", "name": "株式会社〇〇"},
  {"tel": "06-9876-5432", "name": "△△有限会社"}
]
```

自分でデプロイする場合は `MASTER_DATA` の設定が必要です。

</details>

## 💻 開発環境のセットアップ

### 必要なもの

- Node.js
- Python 3.9以上

### リポジトリをクローン

```bash
git clone <リポジトリURL>
cd <リポジトリ名>
```

### バックエンドのセットアップ

```bash
cd backend
pip install -r requirements.txt

# サーバー起動
python -m fastapi dev main.py
```

### フロントエンドのセットアップ

```bash
cd frontend
npm install
npm run dev
```

`.env.example` を参考に `frontend/.env.local` を作成してください。
